# Controls

Mouse and keyboard controls for the map and the game clock.

| Control          | Effect                                                       |
| ---------------- | ------------------------------------------------------------ |
| Click a villager | Select them and open the **People** tab.                     |
| Double-click     | Select a villager and follow them with the camera.           |
| Scroll wheel     | Zoom in or out, keeping the point under the cursor in place. |
| Drag             | Pan the map.                                                 |
| `Space`          | Pause or play.                                               |
| `1` `2` `3` `4`  | Speed 1×, 2×, 4×, 8×.                                        |
| `+` / `-`        | Zoom in or out around the centre.                            |
| `0`              | Show the whole village.                                      |
| `F`              | Follow the selected villager, or stop following.             |
| `Esc`            | Deselect.                                                    |

Keys are ignored while you type in a text field. The buttons in the bottom-right corner of the map do the
same as `+`, `-`, `0` and `F`.
